Concrete Pavement 02 (2K)
Source: https://polyhaven.com/a/concrete_pavement_02
License: CC0

Downloaded maps:
- Diffuse / Base Color
- OpenGL Normal
- Ambient Occlusion

The Unity material uses 0.65 x 0.65 tiling so the pavement slabs appear larger.

For sidewalks that need to follow bends, use "Concrete Pavement - Curve Aligned"
with Tools > CYDOY > Sidewalk > Apply Large Slabs + Align Selected Curves.
